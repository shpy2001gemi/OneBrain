# OneBrain vNext Foundation Vectors

`canonical-v1.json` is the frozen, implementation-neutral fixture for
`onebrain/canonical/1`. Every crate consumes the same file; expected digests are
stored values and are never regenerated by a conformance test.

The fixture currently covers canonical/minimal CBOR, malformed inputs, NFC
validation and all reserved v1 domain separators. `identity-object-v1.json`
freezes full-width identities and immutable object envelopes.
`feed-event-v1.json` freezes FeedInception and signed event envelopes, including
tamper rejection and opaque preservation of an unknown event type.

`ku-core/examples/foundation_vector_digests.rs` is a maintainer aid for proposing
a new vector revision. Its output is not an oracle: changes require review
against `CANONICAL_PROFILE_V1.md` before replacing a frozen expected value.
