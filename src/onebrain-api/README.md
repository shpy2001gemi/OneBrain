# onebrain-api

> OneBrain REST/WebSocket API — headless server interface.

| Field       | Value                               |
|-------------|-------------------------------------|
| **Tech**    | Rust (Axum/Warp) + onebrain-node    |
| **Phase**   | Phase 6                             |
| **Status**  | 🏗️ Scaffold                         |

## Overview

Provides a headless HTTP + WebSocket API for controlling an OneBrain node
programmatically. All UI frontends (web, desktop, mobile, glasses, bot,
extension) connect through this API layer.
