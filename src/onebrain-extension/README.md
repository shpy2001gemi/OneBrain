# onebrain-extension

> OneBrain Extension — browser extension.

| Field       | Value                                     |
|-------------|-------------------------------------------|
| **Tech**    | TypeScript + WebExtensions API            |
| **Phase**   | Phase 10+                                 |
| **Status**  | 🏗️ Scaffold                               |

## Overview

Browser extension for Chrome, Firefox, and Edge. Enables inline
knowledge capture and retrieval while browsing the web, connecting
to the local OneBrain node via onebrain-api.
