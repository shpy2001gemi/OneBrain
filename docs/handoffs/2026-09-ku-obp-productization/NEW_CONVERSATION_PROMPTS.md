# Conversation entry points

Use the single maintained resume prompt in [NEXT_CONVERSATION](NEXT_CONVERSATION.md).
Current task/state is in [PROGRESS](PROGRESS.md); acceptance is in the parent task;
scope and deferred work are in [MASTER_PLAN](MASTER_PLAN.md). D-044 governs MVP
priority. This file deliberately does not duplicate the resume text or status.

For a review, name the parent task and inspect its actual available diff, including
relevant uncommitted/unmerged work. Run only appropriate focused checks and record
findings in the existing task/ledger. Do not require strict production qualification
for a scoped concept demo.

For a merge/publication request, identify the exact branch/content first, preserve
unrelated work, and update the ledger with the actual result. A new chat or subtask
is not authorization to reset, clean or delete retained work.
