# Task outputs

Accepted analysis, inventories and evidence summaries created by tasks in this
workstream belong here. Source code, canonical specifications and generated
test artifacts remain in their normal repository locations.

Expected named outputs include:

- `KU_AUTHORITY_AUDIT.md` from `KU-REV-001`;
- [KU_RUNTIME_GAP_MAP.md](KU_RUNTIME_GAP_MAP.md) from `KU-REV-002` (the task's declared filename);
- [KU_ENCODER_FRAMEWORK_RESEARCH.md](KU_ENCODER_FRAMEWORK_RESEARCH.md), the
  D-017 research/overlap map and design input for KU-ENC-001/002/003;
- per-task evidence summaries when the corresponding task contract requires
  one and an existing canonical evidence location does not already exist.

Do not use this directory as a second progress ledger. Task state and commit
evidence belong in [`../PROGRESS.md`](../PROGRESS.md).
