# KU-ENC-003 — Multi-model encoder and constrained-host qualification

> State: Planned
> Branch: `codex/ku-enc-003-model-qualification`
> Depends on: `KU-ENC-002` merged

## Objective

Measure model-independent contract conformance, semantic extraction quality,
convergence and resource costs before advertising a local encoder as ready.

## Required read set

- KU-ENC-001 contract/corpus/gates and KU-ENC-002 implementation evidence;
- [research evaluation design](../outputs/KU_ENCODER_FRAMEWORK_RESEARCH.md);
- model manifest/supply-chain and fidelity authority profiles;
- existing MOB-06 benchmark boundaries; mobile implementation requires its
  own full mobile build contract, not an exception from this task.

## Deliverables and acceptance

- Reproducible runner/report binding source corpus split, exact model weights,
  tokenizer, quantization, backend/build, chat template, schema/prompt/compiler,
  Registry root, inference options and device/resource configuration.
- At least two real model families, repeated runs, a no-LLM baseline and a
  constrained-memory host lane. Report absent hardware/provider lanes as
  unqualified; do not invent numbers or substitute mocks for measured evidence.
- vi/en and adversarial corpus; independent quality/coverage/abstention/error
  metrics, no silent filtering of failed cases from convergence denominators.
- Exact bytes/CIDs for identical validated SEM, measured raw-text agreement
  with alternatives preserved; no winner-by-majority or truth claims.
- Cold/warm p50/p95 end-to-end latency, stage/token/call counts, peak memory
  including KV cache, cancellation/OOM/process-death and privacy evidence.
- Ablate legacy tool/v2 behavior only in an isolated harness without write
  authority. Compare gains while preserving coverage and qualifier fidelity.
- Gates and thresholds fixed before holdout evaluation. Publish qualification
  manifests only for measured passing tuples; a valid outcome is rejecting a
  model/profile and keeping no-LLM/manual draft available.
- Reuse physical mobile results through MOB-06; desktop/low-memory simulation
  does not close mobile thermal/energy/background or release gates.

## Excluded

Automatic model downloads, unapproved source disclosure, mobile app changes,
default rollout, new canonical semantics and delegated/reward qualification.
