collapsing validation, saving, publication, Use or adoption boundaries.

## Required read set

- package README/decisions/progress

- Create/preview/validate/save/revise/search/inspect states match API DTOs.
- Private/local/published status and limitations are visible and unambiguous.

- No client-side reconstruction of canonical identity or authority.
- Accessibility, focused component tests and production Web build pass.
