# OBP-QA-001 — Outbound-first desktop product acceptance

> State: Planned
> Branch: `codex/obp-qa-001-nat-canary`
> Depends on: `OBP-CLI-001` and `OBP-DESK-001` merged

## Objective

Prove the bounded product claims for two ordinary consumer nodes using
outbound-only relay connectivity, independent relay operation, bootstrap
source loss, relay failover, restart and privacy controls.

## Required read set

- `../README.md`, `../DECISIONS.md`, `../CAPABILITY_STATUS.md`, `../PROGRESS.md`
- accepted OBP product, API, CLI, Web and Desktop contracts/evidence
- outbound-first acceptance sections and current P5/production evidence rules
- existing NAT, failover, reconciliation, privacy and restart harnesses

## Deliverable

Versioned acceptance scenarios and evidence for:

- two consumer application nodes with no inbound port-forwarding;
- two independently configured vNext `onebrain-relay` instances;
- initial bootstrap by DNS or direct IP plus expected NodeID;
- learned approved sources after initial bootstrap outage;
- selected-relay loss and alternate-relay recovery;
- bidirectional application exchange when either side initiates intent;
- process restart, durable outbox and reconciliation convergence;
- malicious/incorrect relay, wrong-peer and private-data negative cases;
- consistent CLI, Web and Desktop status.

## Acceptance

- Single-machine simulation is labeled preflight, not independent-network
  production evidence.
- Product claims require the exact host/network/provider evidence prescribed
  by the accepted profile.
- Passing evidence supports Desktop/reference scope only; not mobile, browser,
  mailbox wake, guaranteed availability or global discovery.
- The feature remains default-off after this task.
- All prescribed test and evidence validators pass.

## Excluded

Default rollout, strict Base qualification, mobile/browser and legacy removal.
