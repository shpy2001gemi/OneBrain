# KU-API-001 — Local authenticated KU REST/WS projection

> State: Planned
> Branch: `codex/ku-api-001-local-api`
> Depends on: `KU-RUN-001` merged

## Objective

Project the shared KU service through the frozen local authenticated REST and,
where justified, private WebSocket boundaries.

## Required read set

- package README/decisions/progress
- merged KU product profile
- vNext REST and private WebSocket profiles
- shared KU service public API and focused tests

## Acceptance

- Handlers only parse/authenticate/project; they do not own KU semantics.
- Bearer/private boundaries, opaque pagination and DTO encodings are exact.
- Private source, local identifiers and capabilities do not enter broadcast or logs.
- Slow clients cannot block the service or other subscribers.
- API conformance, auth, negative privacy and service-integration tests pass.

## Excluded

CLI/Web/Desktop presentation and networking endpoints.
